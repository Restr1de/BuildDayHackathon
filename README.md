# ClearChoices

Compare phones for older people. React + Vite + Tailwind CSS, backed by Appwrite.

## Setup
1. `npm install`
2. Copy `.env.example` to `.env` and fill in your Appwrite details
3. `npm run dev`

## Structure
- `src/lib` – Appwrite client and data access
- `src/hooks` – data hooks
- `src/pages` – route pages
- `src/components` – shared UI
